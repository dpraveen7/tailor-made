# Tailor Made

A modern React + Vite website for a premium men's and children's clothing shop.

## Features

- Responsive multi-page design with React Router
- Home, Men's, and Children's collection pages
- High-quality tailoring and fashion images from Unsplash
- Mobile-first responsive styling
- Built for Cloudflare Pages deployment

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npm run preview
npm run deploy
```
